目标架构

统一入口与产品体验

统一承接各类入口，保持一致的身份、会话与结果呈现体验。

办公网浏览器

面向办公场景，承载考勤、制度、流程、资料查询等办公能力集合。

生产桌面云

面向内网生产场景，承载更深的生产数据接入，以及任务执行与协同能力。

企业微信

面向移动智能办公场景，可快捷问答和语音交互等轻量交互方式。

通用 AI 智能体内核

通用 AI 智能体共享的核心能力，负责会话、记忆、任务和结果编排。

会话上下文

维护会话历史、文件选择和上下文状态。

工具调用 Loop

围绕工具选择、skills 选择、子 Agent 选择和继续推理形成闭环。

定时任务

管理多步任务、定时触发、模块执行、工具回调和失败重试。

记忆

沉淀会话记忆、用户记忆和智能体记忆，支撑后续任务与长期上下文。

多智能体接入与调度

统一接入更多内部智能体与外部透传智能体，并负责选择、路由和结果承接。

主智能体

默认承接通用问答、资料理解和基础任务编排。

自定义智能体

专项智能体、领域智能体、部门智能体等自定义智能体统一接入。

接入其它智能体

对接外部智能体或第三方智能体系统，按接入或透传方式转发请求。

文件

模型可直接读取、解析和引用的文件类资源，包括文档、图片、表格和代码包。

知识

模型可检索、可长期沉淀的知识类资源，包括知识库、索引，以及可 RAG、可混合检索的知识接入方式。

工具

模型可调用的原子能力单元，封装业务 API、平台模块、MCP 接入能力，并可扩展接入沙箱工具。

技能

模型可复用的能力包和执行模板，用于封装一组稳定的处理步骤和工作流。

子 Agent

面向特定目标的高阶委派单元，可独立承担子任务并把结果回传给主智能体，例如 deepresearch。

支撑与治理能力

侧向支撑并约束核心流程、底座和能力域。

身份、授权、鉴权与审计

身份识别、授权关系、鉴权校验、可见性控制和操作审计。

观测与评测

日志、Trace、反馈、评测和质量回路。

关系与状态存储

DB 负责会话、任务、权限、记忆、索引状态、授权关系和元数据沉淀。

对象存储

MinIO 等对象存储负责原始文件、衍生产物、结果文件和大对象内容承载。

模型接入基础设施

模型路由、多模型切换、多模态选择和统一调用协议。

架构原则： 产品架构优先，核心能力构建优先；可插拔式扩展资源调度，控好边界与协议；框架不是一成不变的，但每一次迭代都需要慎重考虑。
