# Release List

## 2025-07 & 之前
### GPT助手上线
- 初版聊天助手上线。
- 制度助手上线。
- 内置多智能体能力。

## 2025-08
### Markdown ECharts 渲染
- 支持在 Markdown 中直接渲染 ECharts 图表，验证可支撑智能问数看图表类的场景。

## 2025-09
### GPTs 平台化，现在的更多智能体
- 上线 GPTs 创建与管理 API。
- 支持自定义系统提示词、示例问题。

## 2025-10
### 多应用架构拆分
- 项目拆分为 `assistant-web`、`assistant-dashboard`、`assistant-metrics-api` 三个核心模块。
- 从单体前端演进为“主应用 + 数据大屏 + 统计后端”的多模块架构。
- 这是一次架构重构，后续还会有多次重构。

### 数据大屏上线
- 上线 GPT 助手核心指标总览页面。
- 支持用户数、请求数、热门模型排名等运营分析能力。

## 2025-11

### 图片文档类资源问答支持
- 系统开始支持按模型能力限制上传文件类型。
- 为不同模型区分图片、文档等可上传范围，形成模型能力约束机制。

## 2025-12
### 前端迁移到 Vite
- 前端工程迁移到 Vite，大幅度提升编译效率。
- 虽然偏工程基础设施，但它是后续多应用拆分和前端持续演进的重要拐点。

## 2026-03
### LLM Kernel 基础架构
- 引入 `llm kernel`，将模型处理逻辑从具体助手实现中解耦。
- 形成后续主助手、制度助手、自定义智能体统一演进的内核基础。
- 将附件读取、工具调用、模型执行链路结构化，为知识文件与诊断能力埋下基础。

## v1.0.1(2026-04)

### UI重构，重新设计（辛沛露）
- 重新设计UI，统一风格。
- 预留扩展设计。
- 极大提升了用户体验。

### 版本入口与变更记录
- 侧边栏新增版本号入口。
- 产品内可直接查看版本变更记录。
- 建立了后续正式版本发布的产品化承载入口。

## v1.1.0(2026-05)
### 附件格式扩展
- 主助手新增 Markdown、CSV、PPTX 上传支持。
- 新增格式可进入文本提取与对话分析链路。
- 附件能力从基础文档继续扩展到更多办公与结构化文本场景。

## v1.2.0（2026-06）
### 管理员配置页
- 新增独立管理员后台 `/admin`。
- 管理员可在页面内维护模型配置、权限配置、功能开关和审计记录。
- 聊天历史主数据源从浏览器本地迁移到服务端。
- 为后续权限体系、审计能力和跨设备一致性打下基础。

### SQLite 到 Postgres 历史与业务数据迁移
- 系统支持从旧 SQLite 自动迁移会话历史、附件映射、自定义智能体及相关状态到 Postgres。
- 迁移流程支持分批处理与启动时导入，降低旧数据切换成本。
- 这是从单机轻量存储走向更稳定部署形态的重要基础能力。

## v1.3.0（2026-06）
### 智能体长期知识文件
- 智能体支持挂载长期知识文件，而不再只依赖当前会话临时附件。
- 模型通过文档工具按需读取知识内容，而不是默认把全部正文注入上下文。
- 知识文件生命周期与会话附件分离，形成“长期知识 + 临时附件”的双层文件体系。

### 文件上传安全与治理体系升级
- 上传链路增加归属校验、配额预留、类型签名校验、压缩包防炸弹、防超时解析、跨节点清理互斥等一整套安全治理能力。
- 文件下载、文本提取、聊天读取统一做资源归属控制。
- 上传能力从“能用”升级到“可控、可审计、可清理”。

## v1.5.0（2026-06）
### 智能体与附件端内隔离
- 智能体可见性和普通附件归属默认按登录端隔离。
- 全局智能体可作为例外跨端可见。
- 上传配额、附件复用、会话附件清理开始按用户 + 登录端维度治理。
- 智能体权限统一到 `owner/admin/viewer` ACL 模型，管理入口从后台收口到智能体体系内。

- 自定义智能体开放给特定两名同事，满足需求。

## 6月底一周

## 2027年

## 简单总结
- 核心能力：NUAI -> 制度问答 + 文件问答 -> 多智能体 -> 工具调用 + skills能力 -> 子agent + 容器化执行复杂任务
- 文件数据：浏览器 -> 后端sqlite + 本地文件系统 -> postgress + minio -> 个人资料库
- 安全管控：三端统一入口 -> 用户级隔离 -> 登录端隔离 -> 复杂权限体系
- 后台配置：配置文件 -> 持久化 -> 可运维可治理
